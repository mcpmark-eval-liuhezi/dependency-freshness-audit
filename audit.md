## Reproducing this audit

- `python generate_audit.py > audit.md` regenerates this report. Installed versions are read live from the environment via `importlib.metadata` (read-only; nothing is installed or upgraded).
- `LATEST_STABLE` in `generate_audit.py` is a snapshot of each project's release pages taken on 2026-10-19 (source links in the highlights above). Refresh it before re-running after new releases.
- Ranking rule (deterministic): behind-by-major → priority 4, behind-by-minor → 3, behind-by-patch → 2, missing → 1, current/ahead → 0; ties break alphabetically. Lower rank number = act sooner.
